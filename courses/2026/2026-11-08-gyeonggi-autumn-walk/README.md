# 가을 오후, 어디를 걸을까

- 여행 날짜: 미정. 폴더 날짜는 조사일이며 방문일이 아닙니다.
- 지역: 국내 / 대한민국 / 경기 오산·광주·용인
- 분류: 산책 / 자연 / 데이트 / 후보조사
- 확인일: 2026-11-08
- 출발지·교통·예약: 미정
- 기존 공유 페이지 방침에 맞춰 비용·예상 총액은 생략합니다.

## 코스 선택

가벼운 산책은 물향기수목원, 성곽과 전망은 남한산성을 우선 추천합니다. 네 곳을 하루에 잇지 않고 한 곳씩 선택하는 반나절 후보입니다.

### 물향기수목원

- 가볍게 걷는 날 · 우선 추천
- 위치: 오산시 청학로 211
- 분위기: 정원과 숲길을 천천히 걷고, 산책 뒤 따뜻한 차 한 잔. 편하게 이야기하며 걷는 반나절에 잘 맞아요.
- 운영: 11~2월 09:00–17:00 · 입장 마감 16:00
- 휴관·확인: 월요일 휴원. 공휴일·연휴와 겹치면 다음 평일 휴원. 1월 1일·설날도 휴원.
- 동선: 수목원 입장 → 정원·습지 산책 → 휴식 → 퇴장 후 카페
- 체류: 산책 90–120분 제안
- 참고: 내부에 매점·식당이 없어요. 물을 챙기고 간식은 지정된 쉼터에서 먹어요. 꽃·단풍 상태는 날씨에 따라 달라요.
- [네이버 지도](https://map.naver.com/p/entry/place/35195643)

### 남한산성

- 성곽과 전망 · 걷기 좋은 날
- 위치: 광주시 남한산성면 · 산성로터리 일대
- 분위기: 성곽의 굴곡과 숲, 전망을 함께 보는 코스. 평지 정원보다 오르내림이 있어 운동화를 신고 가요.
- 운영: 야외 성곽길과 행궁은 별도 운영
- 휴관·확인: 행궁: 11~3월 10:00–17:00 · 매표 마감 16:30. 월요일 휴궁, 공휴일은 제외.
- 동선: 산성로터리 → 북문 → 서문 → 수어장대 → 천주사터 → 남문 → 산성로터리
- 체류: 공식 1코스 3.8km · 약 1시간 20분
- 참고: 사진·휴식을 넣어 2시간 정도 여유를 두는 제안이에요. 행궁을 함께 보면 산책 전에 관람하고, 야외 길은 해지기 전에 마쳐요. 비 온 뒤 돌계단과 낙엽길 주의.
- [네이버 지도](https://map.naver.com/p/entry/place/18292884)

### 용인자연휴양림

- 꽃보다 숲 · 조용히 쉬는 날
- 위치: 용인시 처인구 모현읍 초부로 220
- 분위기: 숲길과 데크, 잔디광장 주변에서 쉬는 코스. 산 정상까지 오르기보다 컨디션에 맞춰 짧게 왕복해요.
- 운영: 11~2월 09:00–17:00 · 입장 마감 16:00
- 휴관·확인: 일일입장·숲길 통제와 임시 휴무는 방문 전 공식 공지 확인.
- 동선: 입구 → 데크·숲길 산책 → 잔디광장 휴식 → 입구로 복귀
- 체류: 산책·휴식 90–120분 제안
- 참고: 사진의 18시 마감 대신 동절기 17시 마감을 적용했어요. 산불조심기간에는 등산로가 통제될 수 있어요. 당일 입장 예약 필요 여부는 031-336-0040으로 확인해요.
- [네이버 지도](https://map.naver.com/p/entry/place/13179328)

### 용인농촌테마파크

- 정원과 원두막 · 사진 속 장소 추정
- 위치: 용인시 처인구 원삼면 농촌파크로 80-1
- 분위기: 꽃정원과 농촌 풍경을 구경하고 원두막에서 잠깐 쉬는 코스. 사진 속 네 번째 장소로 추정해 후보로 보관했어요.
- 운영: 11~2월 09:30–16:30 · 매표 마감 16:00
- 휴관·확인: 월요일 휴관. 월요일이 공휴일이면 운영하고 화요일 대체휴관. 1월 1일·설 및 추석 연휴 휴관.
- 동선: 입구 → 정원 산책 → 원두막 휴식 → 농경문화전시관 선택 관람
- 체류: 산책·관람 60–90분 제안
- 참고: 네 곳 중 마감이 가장 빨라 오후 2시 전후 도착을 권해요. 체험과 원두막 이용 방식은 별도 확인이 필요해요.
- [네이버 지도](https://map.naver.com/p/entry/place/13327760)

## 공통 확인

오후 2시 전후 도착 → 산책 → 해지기 전 마무리 → 카페를 제안합니다. 카페·식당과 실제 이동시간은 미정입니다. 출발지 불명의 사진 속 이동시간은 사용하지 않았습니다. 사진 오른쪽 아래의 다섯 번째 장소는 미확인으로, 화담숲으로 단정하거나 후보에 포함하지 않았습니다.
