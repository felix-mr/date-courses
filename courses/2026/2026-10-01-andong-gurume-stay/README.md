# 안동, 고택에서 쉬는 하룻밤

- **상태:** 앞으로 가보고 싶은 후보 · 예약 없음
- **여행 날짜:** 미정
- **조사일:** 2026-10-01 (폴더 날짜는 여행일이 아닌 조사일)
- **지역 구분:** 국내 · 대한민국 · 안동 · 경북
- **추천 길이:** 1박 2일 (계획 제안)
- **카테고리:** 이색숙소 · 산책 · 1박 · 후보조사

## 어떤 여행인가요

전통리조트 구름에에서 쉬고 월영교를 걷는 밤. 다음날은 구시장 찜닭 한 상으로 마무리해요.

- 이동 제안: 자동차 이동 제안
- 숙소 후보: 전통리조트 구름에 · 예약 미정

## 추천 흐름

먼 곳을 여러 군데 묶기보다, 고택에서 보내는 시간을 넉넉하게 남기는 여행이에요.

- **첫날 · 고택에서 쉬기 · 전통리조트 구름에** — 전통 고택에 현대식 욕실과 실내 온도조절을 더한 숙소. 방의 모양과 욕실 위치를 비교해 둘에게 맞는 객실을 골라봐요. [네이버 지도](https://map.naver.com/p/search/%EC%95%88%EB%8F%99%20%EC%A0%84%ED%86%B5%EB%A6%AC%EC%A1%B0%ED%8A%B8%20%EA%B5%AC%EB%A6%84%EC%97%90)
- **첫날 저녁 · 강변 산책 · 월영교** — 강 위 나무다리와 주변 산책로를 천천히 걸어요. 숙소로 돌아가기 전, 저녁 풍경을 함께 보는 시간이에요. [네이버 지도](https://map.naver.com/p/search/%EC%95%88%EB%8F%99%20%EC%9B%94%EC%98%81%EA%B5%90)
- **둘째 날 · 점심 · 안동 구시장 찜닭골목** — 여러 찜닭집이 모인 골목에서 둘이 나눠 먹을 한 상을 골라요. 특정 식당은 날짜를 정한 뒤 선택해요. [네이버 지도](https://map.naver.com/p/search/%EC%95%88%EB%8F%99%20%EA%B5%AC%EC%8B%9C%EC%9E%A5%20%EC%B0%9C%EB%8B%AD%EA%B3%A8%EB%AA%A9)

## 날짜가 정해지면

- 구름에는 객실마다 욕실 위치가 달라요. 내부 욕실 있는 객실부터 살펴보고 침구·포함 식사·취소 조건을 확인해요.
- 고택 내 취사는 금지돼 있어요. 월영교 야간 운영 공지와 선택한 찜닭집의 영업일을 여행 날짜에 맞춰 확인해요.

운영·요금·교통·숙소·식당은 실제 여행일에 맞춰 재검증합니다. 기간·동선·숙소·식당은 조사 기반 후보 제안이며 확정 예약이 아닙니다.
