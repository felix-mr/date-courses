# 수원 케이크 카페와 산책 후보

- 조사일: 2026-10-07. 폴더 날짜는 조사일.
- 여행 날짜: 미정. 기존 10월 10일 계획은 사용자 요청으로 취소.
- 구분: 국내 · 대한민국 · 경기 수원.
- 카테고리: 맛집 · 산책 · 데이트 · 후보조사.
- 상태: 후보, 예약 미정.

## 제안

스퀘어드(1순위) 또는 콜링우드 → 화홍문·방화수류정·용연 산책 → 저녁(식당 미정).
기존 제안 시간은 17:00 카페, 18:15 산책, 19:00 저녁. 새 약속 시간은 미정.
스퀘어드 공식 안내 12:00–21:00, 공개 메뉴에 가을 무화과 케이크. 콜링우드 공개 안내 12:00–21:00, 주문 마감 20:30; 생망고케이크·초코무스 등 공개 메뉴 확인. 당일 메뉴·재고·좌석은 미확인.
