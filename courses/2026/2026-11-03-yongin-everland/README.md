# 11월 3일 · 처음 가는 에버랜드

[하루 일정 보기](course-options.html)

- 방문일: 2026년 11월 3일 화요일, 낮 12시 조금 지나 입장 예정
- 인원: 2명 / 종일권
- 이동: 기흥역에서 만나 에버라인 이용 (사용자 확정). 만남 시각·역내 위치 미정.
- 본인 티켓: 앱 등록 완료 (사용자 확인)
- 여자친구 티켓: 11월 3일 현장 구매 예정. 구매·등록 완료가 아님.
- 장소: 경기 용인 에버랜드 / 국내 · 동물원 · 놀이공원 · 데이트
- 상태: 방문 예정. 실제 방문·탑승 후기는 아직 없음.
- 확인일: 2026년 11월 2일

## 가는 길·귀가

- 기흥역 만남 → 에버라인 전대·에버랜드행 → 종점 하차 → 3번 출구 → 정문 셔틀 → 에버랜드.
- 수인분당선 도착 시 에버라인 환승 표지 이용. 열차 이동 외에 셔틀 대기·현장 발권 시간도 고려.
- 귀가: 정문 → 역 방면 셔틀 → 전대·에버랜드역 → 기흥행.
- 공식 운행시간상 전대·에버랜드역 기흥행 막차 23:30. 운행 사정에 따라 변경 가능. 셔틀 종료 시각과 기흥 이후 각자 귀가편은 별도 확인 필요.
- [기흥역 지도](https://map.naver.com/p/search/%EA%B8%B0%ED%9D%A5%EC%97%AD%20%EC%97%90%EB%B2%84%EB%9D%BC%EC%9D%B8)

## 현장 순서

1. 매표소에서 여자친구 종일권 구매. 발권 대기시간 고려.
2. 본인 앱 에버포켓에 여자친구 이용권도 등록. 문제가 있으면 매표소에서 확인.
3. 두 사람 모두 게이트 입장 완료 후 스마트줄서기에서 이용권 2장 선택.
4. 사파리·판다 중 우선순위 시설의 줄서기 상태 확인. 마감이면 해당 시설의 현장 안내를 따르거나 다른 곳 선택.

스마트줄서기 잔여분과 실제 대기시간은 미확인. 정오 입장으로 인기 시설 이용을 보장할 수 없다. 모든 시설이 특정 시각에 현장 줄서기로 전환된다고 단정하지 않는다.

## 추천 일정

시간대는 제안이며 예약된 일정이 아니다. 동물시설 1–2곳, 타고 싶은 놀이기구, 야간 퍼레이드를 중심으로 선택한다.

- 12시대: 현장 발권 → 앱 등록 → 두 사람 입장 → 첫 줄서기. 점심을 못 먹었다면 먼저 식사.
- 13–16시: 주토피아. 사파리월드·판다월드 중 한 곳부터. 여유가 있으면 와일드 사바나 익스페디션 도보 관람 추가.
- 16–19시: 대기시간을 보며 놀이기구·저녁. 스릴을 좋아하면 모니모RUSH(옛 T익스프레스) 우선 확인.
- 19:30: 문라이트 퍼레이드 약 30분. 관람 위치는 당일 앱 지도에서 확인. 이후 야경과 귀가.
- 낮 공연 대안: 13:30 스마일리 펌킨 퍼레이드 약 35분. 선택하면 동물 관람 수를 줄인다.
