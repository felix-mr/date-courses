# 2026-09-30 · 태안·안면도 1박 조사

**카테고리:** 바다 · 대하 · 회 · 1박 · 후보조사

제철 새우와 회를 먹는 1박 여행을 위해 태안·안면도 숙소와 동선을 조사한 기록.

## 계획했던 동선
수원 → 안면도 → 꽃지 일몰 → 생대하/활어회 → 숙소 → 다음날 카페/안면도 자연휴양림 → 수원

## 숙소 후보
- **아일랜드 리솜** — 최우선 후보였으나 원하는 일정에 만실.
- **나문재** — 정원과 자연 속 감성 숙소 후보.
- 이후 만리포와 대천까지 범위를 넓혀 조사.

## 결론
숙소와 생새우회/회 동선을 함께 고려해 **대천 Hotel Solaire**로 최종 변경.
