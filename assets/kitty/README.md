- kitty-hug.png: maintabIcoFriendsselected@3x.png

## 추가 장식

2026-10-01 내장 imagegen으로 추가 생성한 투명 PNG입니다. 공식 배포 이미지와 구분해 제작 이력을 남깁니다.

- kitty-traveler.png: 분홍 여행복, 카메라와 캐리어를 든 키티.

원본 PNG와 알파 채널을 그대로 보존합니다.
